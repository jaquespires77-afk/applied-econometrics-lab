# Applied Econometrics Lab

Repositório de estudos e aplicações em econometria desenvolvidos
durante minha Formação 5.0.

## Objetivo

Construir uma trajetória prática em econometria aplicada,
inferência estatística, inferência causal e análise de dados
econômicos utilizando principalmente Python.

## Conteúdos

- Mínimos Quadrados Ordinários
- Regressão múltipla
- Teorema de Frisch-Waugh-Lovell
- Viés de variável omitida
- Inferência estatística
- Heterocedasticidade
- Erros-padrão robustos
- Dados em painel
- Inferência causal
- Aplicações com dados públicos brasileiros
